Product of Array Except Self

Given an integer array numbers, return an array answer where answer[i] is equal to the product of every element in numbers except numbers[i].

You must solve the problem without using division.

Example 1

Input:
numbers = [1, 2, 3, 4]

Output:
[24, 12, 8, 6]

Example 2

Input:
numbers = [-1, 1, 0, -3, 3]

Output:
[0, 0, 9, 0, 0]

Constraints:

- 2 <= numbers.length <= 10000
- numbers contains integers.
- Do not use division.
