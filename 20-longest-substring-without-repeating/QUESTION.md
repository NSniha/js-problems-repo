Longest Substring Without Repeating Characters

Given a string s, find the length of the longest substring that does not contain any repeating characters.

A substring must consist of consecutive characters from the original string.

Example 1

Input:
s = "abcabcbb"

Output:
3

Explanation:
The longest substring without repeating characters is "abc".

Example 2

Input:
s = "bbbbb"

Output:
1

Explanation:
The longest valid substring is "b".

Example 3

Input:
s = "pwwkew"

Output:
3

Explanation:
The answer is "wke", which has a length of 3.

Constraints:

- 0 <= s.length <= 10000
- s may contain letters, numbers, spaces, and symbols.
