# Convert Sentence to camelCase

A simple JavaScript solution for converting a space-separated sentence into camelCase format.

## Problem Statement

Given a sentence where words are separated by spaces, convert the sentence into `camelCase`.

The resulting string must follow these rules:

- The first word should be completely lowercase.
- Every subsequent word should start with an uppercase letter.
- All remaining letters should be lowercase.
- The final result should contain no spaces.
- Multiple spaces between words should be handled correctly.
- Leading and trailing spaces should also be handled.
